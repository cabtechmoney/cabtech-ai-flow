# CabTech Hub — Frequently Asked Questions

## What is CabTech Hub?

CabTech Hub is a technology brand focused on software development, API integration, workflow automation, and technical support.

## What services does CabTech Hub offer?

The current service categories used by CabTech AI Flow are:

- **Web Development:** Building websites and web applications.
- **API Integration:** Connecting applications and external services through APIs.
- **Workflow Automation:** Automating repetitive business processes with webhooks, AI-assisted processing, and notifications.
- **Technical Support:** Investigating application errors, API failures, database issues, and integration problems.

## How do I request a service?

Submit your name, email address, requested service, and a description of your requirements. Include relevant technical information where available.

CabTech AI Flow can classify the request and prepare a summary and suggested next action.

## What happens after I submit a request?

The CabTech AI Flow prototype receives the request, uses AI to classify it, saves the customer information and classification to a database, and can send a confirmation email through the configured automation workflow.

A confirmation means the request was received. It does not automatically mean that work has started or that a project has been accepted.

## Can CabTech Hub integrate an external API?

API integration is one of the supported service categories. Useful information to provide includes the API documentation, the system you want to connect, the intended data flow, and any error messages you have encountered.

Never send passwords, private API keys, or other secrets in a support request.

## Can CabTech Hub automate repetitive tasks?

Workflow automation can connect triggers, application APIs, AI processing, databases, and notifications. The appropriate solution depends on the business process and the systems involved.

## What information should I provide when reporting a technical problem?

Provide the expected behaviour, actual behaviour, steps to reproduce the issue, relevant error messages, the affected system, and what changed before the problem began.

Remove passwords, access tokens, customer secrets, and other sensitive information before sharing logs.

## Does an AI classification guarantee the correct solution?

No. AI classification is an initial assessment that helps organize requests. Complex, ambiguous, or high-impact requests may require human review.

## Are service prices and delivery times fixed?

No fixed prices or delivery times are defined in this knowledge base. They should be confirmed after the requirements and project scope have been reviewed.

## What if my request does not fit a listed category?

Provide a clear description of the outcome you need. The request should be reviewed and assigned to the most appropriate category rather than forcing an inaccurate classification.
